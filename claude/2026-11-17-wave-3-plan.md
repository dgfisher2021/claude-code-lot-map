**Goal:** Build wave 3 of the improvements spec (items 21–30) as version 0.12.0: detail on demand (error reasons, more rows, a recap), where the time and the context went (time share, context cost, a timeline), and a map that tells subagents, files and servers apart and suits more people (reduced motion, high contrast, shapes).

**Architecture:** as in waves 1 and 2:

- **State on the board.** New facts live on the `Board` atom (`types/index.d.ts`), set by hooks in `hooks/register.tsx`.
- **Pure functions read them,** in `hooks/map.ts`, with `hooks/classify.ts` and `hooks/overview.ts` as they are.
- **Every surface uses them:** the SVG (`drawMap`), the cells (`hooks/raster.ts`), the pane (`ui.render` in `register.tsx`), and the window through `feed.json` and `renderer/view.mjs`.
- **Words in `hooks/text.ts`,** in all seven languages.

**Tech Stack:** a TypeScript Claude Code mod (hooks API), with Node renderer scripts.

**Spec:** `claude/lot-map-improvements-spec.md`, items 21–30. Item 31 (the rename) is not in this plan: renaming the repo changes the install id, so it waits for the person's word.

**Upstream:** `alexeyw/lot-map` `next` at `e8efa50` (#96). Ports here: `contextCost` (#83) and `motion` (#40). Their diffs are saved in `$CLAUDE_JOB_DIR/tmp/up/pr83.diff` and `pr40.diff`. Read a file with `gh api 'repos/alexeyw/lot-map/contents/<path>?ref=e8efa50' --jq .content | base64 -d`.

## Global Constraints

- **Labels hold names, never content.** An error's first line (item 21) is content, so it is shown only behind an option, off by default, as `hookReasons` is.
- **Every word a person reads** goes in `hooks/text.ts`, in all of `en`, `ru`, `es`, `fr`, `de`, `it` and `pt`. Each new mark on the map or in the rows gets a line in `legend`, and the legend tests follow: the line count, and every line at most 110 characters with no control characters.
- **Loader rules:**
  - `$.env.get` takes a literal name.
  - A function that receives `$` must be declared at the top of its file.
  - Hooks are written `on('<event>', hook)`.
- **Every hook passes its event on unchanged** and returns what came back. Map work goes inside `quietly(...)`.
- **Tests run in `claude plugin test .`** (about 40 s):
  - Stubs must be registered before the first `$` call.
  - `mock.env` copies its object.
  - A tool's text is the `text` field of the `tool.call` answer.
  - A test file may import only the mod's own files, `claude-code` and `../renderer/*.mjs`.
- **Checks:**
  - `claude plugin validate .` passes.
  - `tsc`: `npx -y -p typescript@5.6.3 tsc -p $CLAUDE_JOB_DIR/tmp/tsc/tsconfig.json`, run from that folder, clean.
  - `node --check` on every `renderer/*.mjs`.
  - Prettier 3.3.3 (`--no-semi --single-quote --arrow-parens avoid --print-width 160`) on new hunks only, never whole existing files. Markdown with plain `prettier@3.3.3`.
- **The board's shape tag** in `register.tsx` becomes `'board-5'` in the first task that adds a field to `Board` or `Entry`, once for the release.
- **Commits** carry no Claude attribution and no symbols such as the row marks; the commit guard refuses them.
- **Version** `0.12.0` in `.claude-plugin/plugin.json`. One CHANGELOG section, `## 0.12.0 (2026-11-17)`, written as each task lands. README and PRIVACY follow each change.
- **The worktree guard** refuses complex inline shell. Write scripts to `$CLAUDE_JOB_DIR/tmp` and run them. No `wt.exe` calls from a task.

## Review Focus

1. **With `motion: reduced`, nothing on any surface moves by itself.** That covers the SVG's animations and the cells' paced repaint; a picture is still redrawn when the board changes. Pinned in Task 2.
2. **An error's reason is cleaned and cut.** With `errorReasons` on, a reason holding control characters, a 5,000-character line, or a secret-looking string after the first line shows its first line only, cleaned and cut to 72 characters, and never in a notification or a status file. Pinned in Task 1.
3. **A long session's board stays small.** After 5,000 calls the new history (the time totals, the timeline, the satellites) holds no more than its caps, and a frame's work doesn't grow with the session. Pinned in Tasks 4, 7 and 8.
4. **The map's new marks never cover a station's name or count.** The timeline strip, satellites and subagent labels keep clear of them at the dock's 60x22 cells and in the 460-wide SVG. Pinned in Tasks 7, 8 and 9.
5. **`/workmap log` and the window's extra rows never show more than the board keeps,** and say so when older calls are gone. Pinned in Task 6.
